1. **Connectez-vous** à l'application Alliance Web3 Africa
2. **Cliquez** sur "NFT Mine Game" dans la navigation (icône pioche ⛏️)

Choisissez parmi 3 zones en Guinée:

- Densité: 75/100
- Biodiversité: 90/100 ⚠️
- Risque: Élevé
- **Zone protégée** - Compensation requise

⛰️ **Plateau de Fouta**
- Ressource: Bauxite
- Densité: 85/100
- Biodiversité: 70/100
- Risque: Moyen

💎 **Bassin du Niger**
- Ressource: Diamant
- Densité: 60/100
- Biodiversité: 95/100 ⚠️⚠️
- Risque: Critique
- **Zone protégée** - Compensation élevée

### Étape 2: Choisir le Mode d'Exploitation

🔨 **Artisanal**
- ✅ Faible pollution
- ⚠️ Gains modestes
- 💰 Coût bas
- ⭐ +30 XP

⚙️ **Semi-Mécanisé**
- ⚠️ Pollution moyenne
- 💰 Gains moyens
- 💰 Coût moyen
- ⭐ +80 XP

🏭 **Industriel**
- ❌ Pollution élevée
- 💰💰 Gains élevés
- 💰💰 Coût élevé
- ⭐ +150 XP

### Étape 3: Lancer la Simulation

1. Cliquez sur **"Lancer la Simulation"**
2. L'algorithme calcule automatiquement:
   - Ressources extraites
   - Revenus en عLK3
   - Impacts environnementaux
   - Score ESG final
   - XP gagné

### Étape 4: Consulter les Résultats

Après chaque simulation, vous recevez:
- 💰 Revenu en عLK3
- ⭐ Points XP
- 📊 Score ESG (0-100)
- 📈 Détail des impacts:
  - Pollution eau
  - Dégradation sol
  - Perte biodiversité
  - Émissions carbone
  - Impact population

## 📊 Comprendre le Score ESG

Le **Score ESG** (0-100) est calculé ainsi:

```
ESG Score = (
  100 - water_pollution +
  100 - soil_degradation +
  100 - air_pollution +
  100 - biodiversity_loss +
  100 - carbon_emissions_normalized +
  100 - population_impact +
  100 - infrastructure_damage
) / 7
```

**Interprétation**:
- **90-100**: Excellent 🌟
- **70-89**: Bon ✅
- **50-69**: Moyen ⚠️
- **30-49**: Faible ❌
- **0-29**: Catastrophique 🚫

## ❓ FAQ

### Puis-je perdre mes NFT?
Non, les NFT sont permanents. Seule la réputation ESG peut baisser.

### Comment gagner de l'عLK3?
Simulations, vente NFT marketplace, staking (Phase 2).

### Zones protégées = interdites?
Non, mais compensation obligatoire (coûte plus cher).

### Peut-on jouer hors ligne?
Non, connexion requise pour sauvegarder données ESG.

### Le jeu est-il gratuit?
Oui, simulations gratuites. NFT payants (Phase 2).

### Impact réel garanti?
Oui, fonds escrow financent projets verts vérifiés.
